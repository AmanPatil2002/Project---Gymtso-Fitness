# Gymtso Fitness

Gymtso Fitness is a stylish fitness landing page built using HTML and CSS. The project presents a modern gym website layout with sections for the hero banner, about us, training classes, and weekly schedules.

## Preview

![Gymtso Fitness Website Preview](Gymso%20Fitness.png)

## Features

- Clean and modern landing page design
- Attractive hero section with call-to-action buttons
- About section showcasing trainers
- Training class cards for yoga, aerobic, and cardio
- Weekly workout timetable

## How to View

1. Open the project folder in your browser.
2. Open [index.html](index.html) to view the website.
3. You can also run it with a live server in VS Code for a better preview.
